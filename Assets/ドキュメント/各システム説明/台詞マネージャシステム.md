# データ項目

- 台詞ブロック
    - 台詞の内容の文字列
    - 吹き出しの種類
    - 誰が発言したかの情報（顔アイコンと関係する）
    - 透明度
- 台詞ログ
    - 複数の台詞ブロックを保持し、画面右側に並べて表示する

# クラス説明

- DialogueBlock（台詞ブロック）
    - MonoBehaviourを継承する
    - アタッチ対象は台詞1件を表示するGameObject（UI要素）
    - 与えられた情報（内容文字列・吹き出しの種類・発言者情報・透明度）から自身のUIを初期化する責務を持つ
    - テキスト表示にTMPro（TextMeshPro）を使う
    - 発言者情報は顔アイコン表示と対応する

- DialogueLog（台詞ログ）
    - MonoBehaviourを継承する
    - アタッチ対象は画面右側の台詞表示エリア（例: 縦長のコンテナ）
    - 複数の台詞ブロックを保持し、並べ替え・追加について責任を持つ
    - 新しい台詞を下に、古い台詞が上になるように並べる
    - 新しい台詞を追加すると既存の台詞が上にズレる（HorizontalLayout等のレイアウトを使用する）

- DialogueManager
    - Monobehaviorを継承する
    - シングルトンパターンを採用
    - 台詞のトリガー管理とコルーチン起動について責任を持つ。トリガーに応じて台詞ブロックを作成し、台詞ログに追加する
    - OnCardPlayed (Card card): カードがプレイされたことをトリガーに台詞ブロックを作成して台詞ログに追加するコルーチンを起こす
    - OnUnitDestroyed (Unit unit): ユニットが破壊されたことをトリガーに台詞ブロックを作成して台詞ログに追加するコルーチンを起こす
    - OnCustomTrigger (string triggerId): 外部から指定したトリガーIDで台詞ブロックを作成して台詞ログに追加するコルーチンを起こす
    - 外部からこのマネージャにアクセスしてトリガーできるようにする

# 処理シーケンス

## カードプレイ時の台詞トリガーの処理シーケンス

1. プレイ検知（ゲームフロー管理・操作アニメーション → DialogueManager）
    - カードがプレイされた
    - OnCardPlayed(card)が呼ばれる

2. トリガー判定（DialogueManager）
    - 該当カードに紐づく台詞ブロックとして表示する内容が決まるか確認する
    - 決まる場合、台詞用のコルーチンを起動する

3. コルーチン実行（DialogueManager）
    - 台詞ブロックを生成し、与えられた情報で初期化して、台詞ログに追加する
    - 他のゲーム処理と並行して実行される

## 破壊時の台詞トリガーの処理シーケンス

1. 破壊検知（戦闘システム → DialogueManager）
    - ユニットが破壊された
    - OnUnitDestroyed(unit)が呼ばれる

2. トリガー判定（DialogueManager）
    - 該当ユニットに紐づく台詞ブロックとして表示する内容が決まるか確認する
    - 決まる場合、台詞用のコルーチンを起動する

3. コルーチン実行（DialogueManager）
    - 台詞ブロックを生成し、与えられた情報で初期化して、台詞ログに追加する

## 外部トリガーの処理シーケンス

1. トリガー呼び出し（任意のシステム → DialogueManager）
    - 外部システムがOnCustomTrigger(triggerId)を呼び出す
    - トリガーIDに応じた台詞を再生したい場合に使用する

2. トリガー検索（DialogueManager）
    - triggerIdに紐づく台詞ブロックとして表示する内容が決まるか検索する

3. コルーチン起動（DialogueManager）
    - 該当する内容が決まれば、台詞ブロックを生成し、与えられた情報で初期化して、台詞ログに追加するコルーチンを起動する
